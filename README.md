# HEXA CRAFT - Custom Keyboard Atelier (Venom 60HE Line)

프리미엄 커스텀 키보드 스튜디오 & 온라인 판매 플랫폼입니다.  
모던한 블랙 & 그레이 투톤 미학을 기반으로, 베놈 60HE 마그네틱 자석축 라인업과 카본파이버/알루미늄 보강판, 다양한 커스텀 하우징(Tofu60 2.0 등)을 실시간으로 조합하는 인터랙티브 빌더와 사운드 랩을 제공합니다.

## ✨ 주요 기능
- **인터랙티브 3D/비주얼 커스텀 빌더**:
  - 베놈 60 / 60HE / 60HE v2 기판 선택
  - 특주 카본 파이버 / CNC 알루미늄 보강판 선택
  - Tofu60 2.0, Blade60, Freebird60 등 60% 하우징 모델 & 블랙/그레이 투톤 마감
  - 체리 프로파일 PBT 이중사출 키캡 테마
  - 게이트론 마그네틱 제이드 / RAW HE 자석축 스위치
  - 황동 무게추 레이저 각인 실시간 시뮬레이션
- **웹 오디오 사운드 랩 (Web Audio API)**:
  - 무설치 브라우저 신디사이저로 자석축 타건음(Magnetic Thock/Clack) 실시간 청음
  - 실제 물리 키보드 타건 및 가상 키 클릭 반응
- **쇼케이스 & 장바구니/주문 견적 시스템**:
  - 완제품 컬렉션 탭 필터링
  - 슬라이드형 장바구니 드로어 및 견적서 클립보드 복사
